## Why Practice

- We're here to learn how to put the tools we've been learning together to solve our own problems
- Making this transition from learning information to implementing it requires practice & struggle
- We're going to be doing a bunch of exercises with less guidance

## Key things to think about

- What data type you are working with, vector vs data frame?
- What tools you have to work with that data type?
- What is the input, i.e., what specific vector/data frame
- What your output should be

## Process

- Write code one step at a time
- Check that it's doing what you expect
- Write the next step
